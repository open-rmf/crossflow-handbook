This repo is where the [crossflow handbook](https://open-rmf.github.io/crossflow-handbook)
is hosted so it can be served by [GitHub pages](https://pages.github.com/). The
generated files exist on the `gh-pages` branch, automatically generated from the
[source code in the crossflow repo](https://github.com/open-rmf/crossflow/tree/main/handbook).

We host the handbook on a separate repo because the `gh-pages` branch of the original
[crossflow repo](https://github.com/open-rmf/crossflow) hosts the
[live demo of the diagram editor](https://open-rmf.github.io/crossflow).
GitHub only provides one Pages per repo.

This repo is not open to pull requests or issue tickets. Please direct any change
recommendations to [the crossflow repo](https://github.com/open-rmf/crossflow/tree/main/handbook).
